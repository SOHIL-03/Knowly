Firestore can store embeddings and run nearest-neighbour queries

Firestore documents can hold vector fields, and a nearest-neighbour query returns the documents whose embeddings are closest to a query vector, using Euclidean, cosine or dot-product distance. A vector index is required, and the documentation lists 2048 as the maximum supported embedding dimension. Read the vector search guide

Keeping Cloud Run instances warm

Cloud Run lets you set a minimum number of instances so that some containers stay ready and requests avoid a cold start. Idle minimum instances are billed, so the guide suggests using them where start-up latency matters. Configure minimum instances

Retries and dead letters for Pub/Sub subscribers

Pub/Sub can forward messages that repeatedly fail delivery to a dead-letter topic once a maximum number of delivery attempts is reached, and subscriptions can use a retry policy with exponential backoff. Handling message failures

HTTP target tasks in Cloud Tasks

Cloud Tasks can send HTTP requests to any endpoint, including Cloud Run services, and can attach an OIDC token so the receiving service can check who called it. Queues control dispatch rate and retry behaviour. Create HTTP target tasks

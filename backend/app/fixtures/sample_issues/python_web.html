Dependencies in FastAPI

FastAPI's tutorial explains its dependency injection system: a path operation declares what it needs with Depends, and FastAPI calls those functions for each request. It is commonly used for shared logic such as authentication or database sessions. FastAPI dependencies tutorial

Models and validation in Pydantic

Pydantic models are classes with typed fields; creating one validates the input data and raises a validation error that lists every field that failed. Pydantic models

Speech recognition in the browser

MDN documents the Web Speech API, which has two parts: speech recognition, for turning a user's speech into text, and speech synthesis. Browser support differs, so apps should keep a typed fallback. Web Speech API on MDN
